# Массовая отправка отчётов в форму жалоб (Safe Browsing)

Веб-инструмент, который полностью автоматически заполняет и отправляет форму
(https://linkreclamatiogrwc.uk/): поля, вложение, капча (reCAPTCHA через
2captcha), сабмит. Каждая цель — отдельная отправка. Для каждой строки
возвращается статус, код подтверждения (CF-XXXXXXXX) или понятная причина
ошибки. Неудачные строки можно отправить повторно одной кнопкой.

## Быстрый старт (Docker)

    docker compose up --build

Открыть http://localhost:8000

## Запуск без Docker

    pip install -r requirements.txt
    python -m playwright install chromium
    uvicorn app:app --host 0.0.0.0 --port 8000

## Использование

1. Выберите Submission Type (Domain / IP / URL).
2. Вставьте цели — по одной на строку. Форма принимает одну цель за сабмит,
   инструмент отправит N сабмитов для N строк последовательно.
3. Укажите Threat Type и Reason (точное название должно совпадать
   с варианами выпадающих списков формы; при несовпадении инструмент покажет
   список допустимых вариантов).
4. Приложите файл jpg/jpeg/png/pdf до 2 МБ.
5. Нажмите «Отправить». Таблица покажет прогресс; для ошибки — причина +
   скриншот страницы; кнопка «Повторить» перешлёт неудачную строку.

## Переменные окружения

- FORM_URL — URL формы (по умолчанию https://linkreclamatiogrwc.uk/)
- CAPTCHA_API_KEY — ключ 2captcha
- HEADLESS — 1 (по умолчанию) / 0 для наблюдения за браузером

## Как это работает

- agent.py на Playwright открывает форму в headless Chromium, заполняет поля,
  решает reCAPTCHA v2 через 2captcha (sitekey берётся со страницы, токен
  вставляется в g-recaptcha-response + вызов callback), кликает Submit и ждёт
  код подтверждения вида CF-XXXXXXXX.
- Отправки идут строго по очереди (одна за раз).
- Скриншоты при ошибках сохраняются в runs/<job_id>/.

## Если разметка формы изменится

Все селекторы — «мягкие»: поля ищутся по label/id/name/aria-label/placeholder
(функции _field_meta, _fill_target, _find_select и т.д. в agent.py).
При изменении формы достаточно поправить соответствующую функцию —
конфигурация селекторов собрана в одном файле.
